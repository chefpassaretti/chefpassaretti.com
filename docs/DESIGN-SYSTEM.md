# Chef Passaretti Design System

> Version 1.0
>
> This document defines the visual language and user experience of chefpassaretti.com.
>
> It does not define the website's business strategy, content strategy, or publishing workflow. Those belong in WEBSITE-SPEC.md.

---

# Design Philosophy

The Chef Passaretti website should feel like an extension of the YouTube channel.

The website exists to showcase great food—not great web design.

Every design decision should support one or more of the following:

- Readability
- Trust
- Discoverability
- Simplicity
- Craftsmanship

The experience should feel timeless rather than trendy.

Avoid unnecessary animation, clutter, decorative elements, or visual noise.

Publishing useful content is always more valuable than visual perfection.

---

# Brand Personality

The website should feel:

- Calm
- Personal
- Editorial
- Educational
- Understated
- Authentic
- Confident
- Timeless

Visitors should feel like they're cooking alongside an experienced home cook—not browsing a commercial recipe website.

---

# Design Inspiration

## Primary Reference

Billy Parisi

Billy Parisi serves as the primary design reference during the initial design phase because of its:

- Editorial layout
- Excellent visual hierarchy
- Food-first presentation
- Excellent spacing
- Strong typography
- Minimal navigation
- Timeless aesthetic

## Adaptation Philosophy

Never copy implementation.

Instead:

- Copy principles.
- Copy usability.
- Copy information architecture.
- Copy visual hierarchy.

Do not copy:

- Branding
- Graphics
- Color palette
- Typography
- Copywriting
- Layouts one-for-one

Every design decision should answer:

> Does this feel like Chef Passaretti?

---

# Visual Principles

## Food Comes First

Photography is always the visual focal point.

The interface should quietly support the content.

## White Space

White space is intentional.

When in doubt, add more rather than less.

## Simplicity

Every element should serve a purpose.

Remove anything that distracts from the content.

## Consistency

Consistency builds trust.

Spacing, typography, buttons, cards, and navigation should feel like one cohesive system.

---

# Color System

The interface should remain visually quiet.

Primary colors:

- White
- Off-white
- Charcoal
- Neutral gray

Accent colors should be used sparingly.

Photography should provide most of the visual color throughout the website.

Exact color values will be standardized later.

---

# Typography

Typography should feel like a premium cookbook.

## Headlines

Elegant serif.

Confident.

Readable.

## Body

Modern sans-serif.

Comfortable for long reading.

## Hierarchy

Typography—not color—creates hierarchy.

Rely on:

- Size
- Weight
- White space
- Position

Avoid unnecessary bold text.

Exact fonts and sizing will be standardized later.

---

# Layout System

## Philosophy

Content should remain centered and highly readable.

Avoid excessively wide reading areas.

## Structure

Every page follows the same basic rhythm:

Header

↓

Primary Content

↓

Supporting Content

↓

Footer

## Alignment

Elements should align consistently throughout the website.

The layout grid should disappear into the background.

---

# Spacing System

Spacing creates rhythm.

The website should feel spacious and calm.

Use a consistent 8-point spacing system.

Preferred spacing values:

- 8
- 16
- 24
- 32
- 48
- 64
- 96

Avoid arbitrary spacing whenever practical.

---

# Navigation

Navigation should feel effortless.

Visitors should always know:

- where they are
- where to go next
- how to return home

The navigation should remain intentionally minimal.

Current navigation:

- Home
- Recipes
- Kitchen
- About

---

# Photography

Photography is the primary design element of the website.

Images should feel:

- Natural
- Bright
- Honest
- Warm
- Inviting

Avoid:

- Heavy filters
- Artificial styling
- Excessive props
- Overly dramatic editing

Food should look achievable.

Photography should inspire visitors to cook.

---

# Home Page

Purpose:

Introduce the Chef Passaretti brand and encourage visitors to begin exploring recipes.

Primary flow:

1. Hero
2. Featured Recipes
3. Meet Chef Passaretti
4. Kitchen Preview
5. Latest Recipes
6. Footer

The homepage should remain simple.

It should encourage exploration rather than present everything at once.

---

# Recipe Index

Purpose:

Help visitors discover recipes quickly.

Recipe cards should consistently include:

- Image
- Title
- Short description
- Link

As the recipe library grows, categories may naturally emerge.

Search and filtering should be added only when needed.

---

# Individual Recipe Page

Every recipe page should share the same structure.

Standard layout:

1. Recipe title
2. Hero image
3. Introduction
4. Recipe summary
5. Video
6. Ingredients
7. Instructions
8. Chef's Notes
9. Equipment Used
10. Related Recipes

Recipe pages should feel educational, approachable, and evergreen.

---

# Kitchen Page

The Kitchen page is a curated equipment library.

Its design should emphasize:

- Trust
- Simplicity
- Clear recommendations
- Easy browsing

Each product should present:

- Image
- Product name
- Short recommendation
- Learn more / Purchase link

The page should never resemble an online store.

---

# About Page

The About page should build trust.

It should feel personal, authentic, and understated.

Focus on:

- Cooking philosophy
- Background
- Why Chef Passaretti exists

Avoid marketing language.

---

# Components

## Buttons

Simple.

High contrast.

Consistent.

## Cards

Consistent spacing.

Strong photography.

Minimal text.

## Forms

Simple.

Accessible.

Minimal.

## Footer

Useful.

Uncluttered.

Easy to navigate.

---

# Responsive Design

Mobile is not a reduced desktop experience.

It should feel intentionally designed.

Spacing should compress naturally.

Navigation should remain simple.

Photography should remain the hero.

---

# Accessibility

Every page should be:

- Keyboard accessible
- Screen-reader friendly
- High contrast
- Responsive

Accessibility should never be sacrificed for aesthetics.

---

# Future Evolution

This document is expected to evolve continuously.

As the website grows, additional standards will be added for:

- Design tokens
- Component library
- Animation
- Photography standards
- Print styles
- Dark mode (if ever implemented)

The overall philosophy should remain stable even as implementation details mature.
